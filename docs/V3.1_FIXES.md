# Nurse Joyless V3.1 Runtime Fixes

This patch fixes the issue where one browser JavaScript error prevented UI buttons from working.

## Fixed

- Removed blocking external CDN script tags that could fail offline and produce `Uncaught SyntaxError: Invalid or unexpected token`.
- Added a local SVG favicon to remove `/favicon.ico` 404 noise.
- Added robust button rebinding for critical controls:
  - Load demo patient
  - Reset
  - Analyze patient
  - KO calculator
  - Hidden Info Detective
  - Advanced Sparring Lab
  - Replay Observer
  - Test teams
  - Agent console FAB
  - Export buttons
  - Validation and Assistant buttons
- Restored missing `REGRESSION_TEAMS` data for Dragon Spam, Hazard Stack, and Sun Room.
- Added tactile pixel-style click animations for buttons, cards, and the Agent Console FAB.
- Made learnset fallback quieter and conservative when offline.
- Added `npm run dom-smoke` to verify that important UI buttons are bound and that demo/test teams render.

## Validation

Run:

```bash
npm run check
npm run smoke
npm run dom-smoke
```

All three pass in this patch.
