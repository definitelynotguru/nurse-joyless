# Nurse Joyless V3.5 Calibration Cleanup

This patch intentionally stays on the V3.5 line. It is not V3.6.

## What changed

- Removed overwritten duplicate function definitions from `src/app.js` so future patches do not accidentally edit dead code.
- Reframed scoring around three separate ideas:
  - **Identity Confidence**: how strongly the team resembles an archetype.
  - **Structural Quality**: how coherent the team is as a build.
  - **Battle Reliability**: how repeatable the team's win path looks.
- Updated Markdown export wording to state clearly that scores are structural reads, not ladder win-rate predictions.
- Added harsher role-overload penalties for role-compression Pokémon such as Great Tusk, Corviknight, Zapdos, and Iron Treads when they are asked to cover too many jobs at once.
- Replaced the old self-congratulatory V3.5 gauntlet with an adversarial heuristic audit that penalizes fake archetypes, score inflation, weak field control, passive-team overpraise, and hard-zero matchup collapse.
