# Nurse Joyless V3.2 Fixes

## Navigation
- Sidebar now scrolls independently with a pixel-styled scrollbar.
- This fixes clipped navigation on shorter screens while keeping the console sticky on desktop.

## Data loading
- Removed the eager `unpkg` learnset JSON fetch that caused `file://` CORS noise.
- The app no longer tries to fetch remote data on page load.
- Added an on-demand PokeAPI enrichment path for Team Builder Assistant suggestions.
- Offline fallback suggestions remain available for demos and local file use.

## Team Builder Assistant
- Added `Use Online Pokédex` next to `Suggest Additions`.
- When online access is available, suggestions are enriched from PokeAPI type/pokemon endpoints and scored against the current Sparring Lab report.
- If the API fails or the page is offline, the app falls back safely to deterministic recommendations.

## Reasoning panel syncing
- `Run Advanced Lab` and `Analyze patient` now update:
  - Advanced Sparring Lab
  - Archetype detector
  - Structural scoring
  - Assistant
  - Validation
  - Exports
- This fixes stale panels that said "Analyze a team first" after the team had already been analyzed.

## KO calculator cleanup
- Removed duplicate legacy `renderKo()` implementation.
- Reverse KO now accounts for your defensive Tera when checking if the opponent can KO you back.
- KO verdict text is escaped before insertion.

## Safety and hardening
- Removed the startup CORS error path.
- Escaped additional dynamic UI output.
- Regression smoke tests updated for sidebar-era navigation and report panel syncing.

## Validation
Run:

```bash
npm run check
npm run smoke
npm run dom-smoke
```

All three should pass.
