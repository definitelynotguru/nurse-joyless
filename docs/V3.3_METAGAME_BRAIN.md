# Nurse Joyless V3.3 — Metagame Brain

## What changed

V3.3 replaces the old flat Sparring Lab scoring with a metagame-aware reasoning layer:

- Team identity now distinguishes intent, execution, and drift.
- Trick Room is hard-gated: no Trick Room move means no Trick Room identity.
- Stall is capped when fast breakers, pivot chains, offensive items, or setup density are present.
- Balance now rewards pivots, defensive anchors, breakers, progress tools, and controlled win paths.
- Hazard logic is split into Field Control subscores:
  - Hazard Setting
  - Hazard Removal
  - Removal Denial
  - Chip Abuse
  - Pivot Abuse
  - Setter Overload Risk
- Gholdengo / Good as Gold, Ghost spinblocking, Magic Bounce, and Taunt count as removal-denial signals.
- Suggestions are now metagame-aware and prefer Smogon OU data when available.
- Markdown export is now a full report with team import, identity table, scoreboard definitions, field-control breakdown, type triage, matchup matrix, per-Pokemon notes, suggestions, and validation.

## Data behavior

The app does not fetch remote data on initial page load. Online enrichment is only triggered through the Suggest Additions / Smogon button path. If Smogon data is unavailable, the app falls back to local metagame candidates.

## Validation

Validation remains conservative:

- confirmed hard issues are marked invalid;
- missing or uncertain learnset data is a warning, not a false invalid;
- local fallback learnsets cover the regression teams and common modern OU examples used in testing.
